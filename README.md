## Projeto Principal

### CampoBase — Plataforma de Gestão de Obras

**Produto SaaS próprio | Em desenvolvimento e validação**

Plataforma desenvolvida para digitalizar e centralizar a gestão operacional de obras fotovoltaicas, com foco em produção, equipas, hierarquia de obra, registos e relatórios.

O projeto nasce da experiência prática em operações de campo e procura reduzir processos manuais, retrabalho administrativo e falhas de comunicação entre equipas e gestão.

**Stack:** Laravel · PHP · JavaScript · MySQL

🔗 [Conhecer o CampoBase](https://campobase.pt/)

*O código-fonte da plataforma é privado.*
